# Chandan V Reddy — Portfolio Website

A responsive, single-page portfolio in HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing — personalize these items
- Replace `your.email@example.com` in `index.html` with the correct email.
- Replace the LinkedIn and GitHub placeholder URLs with the real profile URLs.
- Add internship dates and a concise, accurate description of work at HAL Avionics.
- Replace the three sample project cards with actual project names, descriptions, technologies and GitHub/demo links.
- Review the skills list and keep only skills you can confidently explain.
- Confirm education dates, institution name and CGPA/percentage.

## Deploy
Upload the extracted folder to GitHub Pages, Netlify or Vercel as a static site. Keep `index.html`, `style.css`, `script.js` and the `assets` folder together.
